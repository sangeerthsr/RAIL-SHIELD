# 🚆 RAIL-SHIELD

## AI-Enabled Mobile & Handheld Railway Security System

> **Detect Early • Respond Faster • Protect Every Journey**

RAIL-SHIELD is an AI-enabled railway security and threat-assessment system designed to assist Railway Protection Force (RPF) personnel across Indian Railways.

The proposed system combines two intelligent field devices:

- 🤖 **AI-Enabled Quadruped Security Robot**
- 📱 **AI-Enabled Handheld Security Device**

Both systems use multi-sensor data collection, edge processing, AI-based sensor fusion, secure communication, GPS/location tagging, and centralized monitoring to support faster identification and management of suspicious events.

---

## 🎯 Problem Statement

Railway security personnel operate across large, crowded, and complex environments such as:

- Railway platforms
- Coaches
- Railway yards
- Ballast areas
- Tunnels
- Restricted areas
- Low-light environments
- Uneven terrain

Traditional manual inspection can require significant effort and may expose personnel to potentially hazardous environments.

RAIL-SHIELD aims to provide a technology-assisted approach for:

- Real-time monitoring
- Non-intrusive screening assistance
- Suspicious-event detection
- Location-based incident recording
- Secure communication
- Centralized monitoring
- Faster security response
- Offline and online operation
